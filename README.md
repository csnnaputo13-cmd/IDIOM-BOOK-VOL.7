## 🌟 Features

### 📖 Review Mode (Flipbook)
- **50 Idiom Cards** - Browse through all 50 advanced leadership idioms with beautiful images
- **🔊 Text-to-Speech** - Listen to full idiom content including:
  - Idiom phrase
  - Meaning
  - Example sentence
  - "Think of it like this" explanation
  - "When to use" tip
- **🔍 Zoom & Pan** - Tap or click images to zoom in and drag to explore details
- **📄 Pagination** - Navigate easily with Prev/Next buttons or Go-To page
- **🎯 Visual Learning** - Each idiom comes with a visual representation
- **🖱️ Mouse Wheel Zoom** - Scroll to zoom in/out on images
- **👆 Pinch to Zoom** - Mobile-friendly pinch gestures

### 📝 Test Mode
- **50 Multiple-Choice Questions** - Test your knowledge of all 50 leadership idioms
- **✅ Submit Answer** - Get detailed step-by-step analysis for each answer
- **📊 Step-by-Step Analysis** - Includes meaning, word definition, context analysis, conclusion, and references
- **🎯 Performance Rating** - Get rated based on your score
- **🏆 Pass/Fail Status** - Passing score: 40/50 (80%)
- **📋 Detailed Results** - See which questions you got wrong with correct answers
- **🔄 Reset Option** - Clear your answers and start over

### 🎨 Design
- **Warm Orange & Dark Blue Theme** - Professional, high-contrast design
- **💜 Purple Accents** - Modern and elegant look
- **📱 Fully Responsive** - Works on desktop, tablet, and mobile
- **3D Button Effects** - Tactile feedback with shadow depth
- **Animated Elements** - Smooth transitions and micro-interactions

## 🚀 How to Use

### Welcome Screen
1. **Enter your name** in the input field
2. **Choose your mode:**
   - 📖 **Review First** - Browse all idioms before testing
   - 📝 **Take Test** - Jump straight to the exam
3. Click **Start** or press **Enter**

### Review Mode
- Navigate with **Prev/Next** buttons or use **←/→** keyboard shortcuts
- **Zoom in/out** using the ➕/➖ buttons, mouse wheel, or +/- keys
- **Drag to pan** when zoomed in
- **Listen to audio** by clicking the 🔊 button or pressing Space/Enter
- **Change voice** using the voice selector dropdown
- **Jump to any idiom** using the Go-To input
- Click **Back to Welcome** to return to the main menu

### Test Mode
1. Select your answer from the 4 options
2. Click **Submit Answer** to see analysis
3. Navigate with **Prev/Next** or **←/→** keyboard shortcuts
4. On Question #50, click **📊 Submit Exam** to finish
5. View your **Congratulations Popup** with score and rating
6. Click **🏆 View Results** for detailed breakdown

## 🔧 Audio Troubleshooting

### Audio not working?
1. **Tap the "Enable Audio" overlay** when prompted
2. **Ensure your browser supports Web Speech API** (Chrome, Safari, Firefox, Edge)
3. **Try a different voice** from the voice selector dropdown
4. **Check device volume** and media permissions
5. **Refresh the page** if audio stops working

### Supported Browsers
- ✅ Google Chrome (Recommended)
- ✅ Mozilla Firefox
- ✅ Apple Safari
- ✅ Microsoft Edge
- ✅ Opera
